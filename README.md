## Логика работы

Бот помогает не пропустить важные даты, узнать, является ли день выходным,
и найти праздник по названию. Поддерживается переключение стран (Россия,
Германия) через настройки.

Основной сценарий диалога:

```text
/start
  │
  ├─► Приветствие + главное меню (reply-кнопки)
  │
  ├─► [Праздники сегодня] ──► вывод события на сегодня + inline «Назад»
  ├─► [Ближайшие 7 дней]  ──► список на неделю + inline «Назад»
  ├─► [Календарь месяца]  ──► только праздники и выходные + inline «Назад»
  ├─► [Поиск праздника]   ──► запрос названия → поиск + inline «Другой поиск»
  ├─► [Настройки страны]  ──► inline-кнопки «Россия» / «Германия»
  └─► [Помощь]            ──► справка

Любой другой ввод → возврат в главное меню с подсказкой.
```

Особенность поиска: используется нечёткое сравнение строк (SequenceMatcher).
Бот прощает опечатки и находит праздники, даже если название введено
с ошибками или частично. Дополнительно проверяется собственный список
популярных негосударственных праздников (День святого Валентина, Хэллоуин,
День смеха и др.).

## Инструкция по запуску

### Требования

- Python 3.11+
- Сообщество ВКонтакте с включёнными сообщениями
- Токен доступа с правами «Сообщения сообщества» и «Управление сообществом»

### Быстрый старт

1. Клонируйте репозиторий:

   ```bash
   git clone https://github.com/Dunky3p1c8last55/holiday-bot.git
   cd holiday-bot
   ```

2. Создайте виртуальное окружение и установите зависимости:

   ```bash
   python -m venv .venv
   source .venv/bin/activate    # Linux / macOS
   .venv\Scripts\activate       # Windows
   pip install -r requirements.txt
   ```

3. Скопируйте шаблон настроек и заполните токен:

   ```bash
   cp .env.example .env
   ```

   Откройте `.env` и укажите `VK_TOKEN`.

4. Проверьте готовность проекта:

   ```bash
   python smoke_test.py
   ```

5. Запустите бота:

   ```bash
   python -m app.main
   ```

6. Напишите сообществу `/start` в личные сообщения.

### Как получить VK_TOKEN

1. Управление сообществом → «Работа с API».
2. Создайте ключ с правами «Сообщения сообщества» и «Управление сообществом».
3. В разделе «Long Poll API» включите Long Poll версии 5.199 или новее,
   тип события «Входящие сообщения» и «Действия с сообщениями».

## Эндпоинты и интеграции

Бот использует **Long Poll API ВКонтакте**, входящие вебхуки не требуются.

Внешние API не используются. Все данные о праздниках берутся из локальной
библиотеки `holidays` и собственного списка популярных праздников.

## Лимиты внешних API

Бот не использует внешние платные API. Ограничения связаны только
с лимитами самого ВКонтакте (стандартные лимиты для ботов) и не требуют
дополнительной настройки.

## Архитектура

```text
app/
├── bot/              слой адаптеров VK (handlers, keyboards, states)
├── domain/           бизнес-логика (сценарий, тексты, поиск)
├── services/         валидаторы ввода
├── config.py         загрузка настроек из .env
└── main.py           точка входа, запуск Long Poll
```

Разделение слоёв:

- `bot/` — только обработка событий VK и формирование ответов;
- `domain/` — сценарий, поиск праздников, форматирование текстов, независим от VK;
- `services/` — валидация пользовательского ввода.

Технологии:

- **vkbottle 4.x** — асинхронный фреймворк для VK API
- **holidays** — производственный календарь разных стран
- **python-dotenv** — загрузка настроек

## Тестирование

```bash
pytest
```

Покрыто:

- валидаторы ввода (`tests/test_validators.py`);
- логика поиска праздников (`tests/test_scenario.py`).

Smoke-проверка инфраструктуры (настройки, валидаторы, поиск):

```bash
python smoke_test.py
```

## Docker

Сборка и запуск:

```bash
docker compose up --build
```

Файл `.env` должен быть подготовлен заранее.
